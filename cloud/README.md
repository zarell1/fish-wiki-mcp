# Cloud MCP Worker

This is the read-only, live-data Streamable HTTP MCP endpoint. It supports current stateless MCP (`2026-07-28`) and legacy initialize-based clients, and calls only the official Fischipedia MediaWiki API. The MCP endpoint itself requires no OAuth or API key. For hosts that expose HTTP GET tools but cannot act as MCP clients, the same tools are available as public JSON routes: `/api/status`, `/api/search`, `/api/page`, `/api/table`, `/api/category`, `/api/pages`, and `/api/recent-changes`. They return the tool result directly and support CORS; see the repository's agent guide for parameters and pagination. A host's HTTP fetch may receive a Cloudflare 403 challenge for this hosted domain; if so, use its HTTP tool directly with Fischipedia's public API.

The Worker entry point is `worker/index.js`; the Site project and MCP capability are declared in `.openai/hosting.json`. Run `bash scripts/build.sh`, then `node scripts/validate-artifact.mjs` and `node tests/worker.test.mjs` to build and check the deployable artifact. `npm run test:integration` makes real requests through the Worker to Fischipedia; it needs network access and does not test the published hosting edge. The active ChatGPT Site currently responds to direct external requests with a Cloudflare 403 challenge before invoking the Worker; fixing that edge policy requires the hosting operator.
