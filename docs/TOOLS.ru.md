# Справочник MCP-инструментов

[English](TOOLS.en.md) · [Русский](TOOLS.ru.md) · [Гайды по подключению](agents.ru.md) · [На главную](../README.ru.md)

Облачный endpoint работает с живым MediaWiki API официальной Fischipedia. Все его инструменты только для чтения. Ответы поиска и списков могут быть постраничными.

## Облачный MCP

| Инструмент | Аргументы | Назначение и ограничения |
| --- | --- | --- |
| `wiki_status` | Нет | Проверить доступ к API; возвращает официальный источник, endpoint, режим и время проверки. `complete: false` означает, что сервер не является полным локальным зеркалом. |
| `wiki_search` | `query` (обязательно), `limit` (1–50, по умолчанию 20) | Найти статьи и фрагменты по тексту. Результаты — кандидаты, не полные страницы и не доказательство полноты. Может вернуть `continue_token`. |
| `wiki_page` | `title` (обязательно), `max_chars` (1–30 000, по умолчанию 12 000) | Прочитать wikitext, категории и ссылку `source_url`. `has_more: true` означает, что текст обрезан; запросите страницу снова с большим лимитом (максимум 30 000). |
| `wiki_table` | `title` (обязательно), `index` (0–100, по умолчанию 0) | Получить одну таблицу как строки и ячейки. Индекс начинается с нуля. Проверяйте заголовки, единицы и примечания. |
| `wiki_category` | `name` (обязательно), `limit` (1–500, по умолчанию 100), `continue_token` | Получить участников категории. Повторяйте вызов с выданным токеном без изменений, пока он не станет `null`. |
| `wiki_pages` | `namespace` (необязательный), `prefix` (необязательный), `limit` (1–500, по умолчанию 100), `continue_token` | Перечислить страницы Wiki. Передавайте токен без изменений до `null`; список всех страниц может быть очень большим. |
| `wiki_recent_changes` | `limit` (1–100, по умолчанию 20) | Получить краткий список недавних правок. Инструмент не перечисляет полную историю и не поддерживает пагинацию. |

### Порядок вызова

1. `wiki_status` — убедиться, что официальный API отвечает.
2. `wiki_search` — найти статьи-кандидаты.
3. `wiki_page` и при необходимости `wiki_table` — проверить первоисточники.
4. `wiki_category` / `wiki_pages` — только когда нужен перечень; продолжать до `continue_token: null`.
5. Указать `source_url` рядом с каждым фактом. Если поле отсутствует, написать «Не указано».

**Важно:** не конструируйте `continue_token`, не обрезайте и не пересобирайте его. Передавайте значение результата напрямую в следующий вызов.

## Локальный MCP

Локальный сервер `fischwiki_mcp.py` читает SQLite-индекс, который предварительно создаётся командой `fischwiki_api.py sync`. Он отличается от облачного:

| Локальный инструмент | Отличие |
| --- | --- |
| `wiki_status` | Показывает покрытие и свежесть локального индекса. Проверяйте полноту до заявлений «все». |
| `wiki_search` | Аргументы `q`, `limit`, `offset`; поиск по фрагментам локального индекса. |
| `wiki_page` | Дополнительно принимает offset, лимит текста и настройки извлечения таблиц/ссылок. |
| `wiki_table` | Читает таблицу из локально сохранённой страницы. |
| `wiki_category` | Использует `offset` и `total`; повышайте offset, пока не просмотрен весь список. |
| `wiki_pages` | Использует `offset`, а также фильтры namespace/prefix. |
| `wiki_failed` | Показывает страницы, загрузка которых завершилась ошибкой при последней синхронизации. В облачной версии отсутствует. |

Локальный MCP не имеет `wiki_recent_changes`; это облачный инструмент. Локальные результаты зависят от успешной синхронизации и могут отставать от Wiki. См. [гайд локальной установки](agents.ru.md#локальный-mcp).

## Локальный REST API и файлы промптов

В корне также лежат `agent_config.json`, `api_tools.json`, `agent_prompt.txt` и `browser_prompt.txt`. Это вспомогательные настройки, не подключённый облачный агент и не URL публичного API.

- `agent_config.json` и `api_tools.json` описывают локальный REST API по адресу `http://127.0.0.1:8765`. Он появится только после запуска `python fischwiki_api.py serve`; перед этим нужен индекс из `python fischwiki_api.py sync`.
- `agent_prompt.txt` — инструкция исследователю для этого локального индексированного API. Она не добавляет инструменты и не подключает MCP.
- `browser_prompt.txt` — инструкция для поиска через браузер. Это не MCP-подключение и не гарантия полного обхода Wiki.
- Для удалённых облачных агентов используйте hosted MCP и [облачный промпт](CLOUD_PROMPT.ru.md), либо официальный HTTP fallback из [гайда выбора маршрута](agents.ru.md#только-ссылка-на-репозиторий).

## Hosted HTTP и прямой MediaWiki API

Если хост-клиент предоставил browser/HTTP tool, но не MCP-клиент, вызывайте hosted JSON-маршруты через GET. База: `https://fish-wiki-mcp.leafy-bream-8099.chatgpt.site/api/`.

| GET-маршрут | Параметры |
| --- | --- |
| `status` | нет |
| `search` | обязателен `query`; необязателен `limit` (1–50) |
| `page` | обязателен `title`; необязателен `max_chars` (1–30000) |
| `table` | обязателен `title`; необязателен `index` (0–100) |
| `category` | обязателен `name`; необязательны `limit` (1–500), `continue_token` |
| `pages` | необязательны `namespace`, `prefix`, `limit` (1–500), `continue_token` |
| `recent-changes` | необязателен `limit` (1–100) |

Каждый маршрут напрямую возвращает JSON-результат инструмента, включая `source_url` и `continue_token`, если применимо. Кодируйте значения URL и передавайте токен продолжения без изменений. Публичные маршруты только для чтения вызывают тот же официальный API Fischipedia, что и MCP. Если хост получает HTTP 403/Cloudflare challenge или не может открыть эти маршруты, используйте его HTTP tool с адресом `https://fischipedia.org/w/api.php`. Ни один вариант не является MCP. Промпт или ссылка на репозиторий не дают модели сетевой доступ; обычный fetch `/mcp` не вызывает MCP. Примеры — в гайде [«Только ссылка на репозиторий»](agents.ru.md#только-ссылка-на-репозиторий).
